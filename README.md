# macOS Volume HUD (Frosted Glass)

A macOS-inspired volume HUD for Windows 11, built as a [Windhawk](https://windhawk.net/) mod.

Bring a macOS-style volume indicator to your Windows desktop with a frosted-glass appearance, smooth animations, and a clean minimalist interface.

## Features

- macOS-inspired volume HUD
- Frosted-glass visual effect
- Sierra, Dark, and Auto theme modes
- Smooth fade-in and fade-out animations
- Anti-aliased speaker icon
- Segmented volume indicator
- Adjustable volume step
- Customizable display duration
- Adjustable HUD position
- Adjustable opacity
- DPI-aware rendering
- Windows Core Audio integration

## Requirements

- Windows 11
- [Windhawk](https://windhawk.net/)

## Installation

1. Download `macos-volume-hud.wh.cpp` from this repository.
2. Install and open Windhawk.
3. Open the Windhawk editor.
4. Import or paste the mod source code.
5. Compile and enable the mod.
6. Customize the settings to your preference.

## Configuration

| Setting | Description | Default |
|---|---|---|
| Volume Step | Volume adjustment amount | 2 |
| Hide Delay | Time before the HUD disappears (ms) | 1500 |
| Bottom Offset | HUD position from the bottom | 120 |
| Opacity | HUD transparency | 100 |
| Theme | Visual theme | Sierra |

### Available Themes

- `sierra` — Light macOS-inspired appearance
- `dark` — Dark appearance
- `auto` — Automatically follows the Windows theme

## Compatibility

Designed for Windows 11.

Compatibility may vary depending on Windows version, display scaling, and system configuration.
